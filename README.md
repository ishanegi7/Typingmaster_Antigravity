# 🕹️ TYPE//TANK

### TYPE. AIM. FIRE. SURVIVE.

TYPE//TANK is a retro DOS-style arcade typing defense game built entirely with HTML5, CSS3, and Vanilla JavaScript.

Take command of a heavy artillery tank and defend your perimeter against hostile words falling from orbit. Type fast, acquire targets, rotate your turret, and destroy incoming threats before they breach your hull.

> Your keyboard is your weapon. Your accuracy is your armor.

---

## 🎮 Gameplay

Hostile words descend toward your defensive perimeter.

Your mission is simple:

**LOCK → AIM → FIRE → SURVIVE**

Type the beginning of an incoming word to acquire a target. Your artillery system locks onto the threat and engages it before it reaches the ground.

As the difficulty increases, enemies become faster, more complex, and harder to eliminate.

Can you keep the perimeter intact?

## ⌨️ Controls

TYPE//TANK is built around a keyboard-first experience.

| Action | Control |
|--------|---------|
| Acquire Target | Start typing the target |
| Engage Target | Continue typing |
| Navigate Interface | Keyboard / Mouse |
| Fire | Automatic after lock |

> 💡 Pro tip: Don't wait for a perfect lock. Start typing as soon as you identify your target.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/your-username/type-tank.git
cd type-tank
```
Start a local server:

python -m http.server

Then open:
```
http://localhost:8000
```
You can also open the HTML entry point directly in a modern browser.
