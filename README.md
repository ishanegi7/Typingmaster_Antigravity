🕹️ TYPE//TANK
A retro DOS-style arcade typing defense game built entirely with HTML5, CSS3, and Vanilla JavaScript.


TYPE//TANK is an intense, keyboard-first tactical typing simulation. Command a heavy artillery tank and defend your perimeter against a barrage of hostile words descending from orbit. Lock onto targets by typing their starting characters, and neutralize them before they breach your hull integrity.

✨ Key Features

Zero External Dependencies: Built completely from scratch without React, external libraries, or image assets.
Procedural Audio: All sound effects (lasers, explosions, damage crunches, and victory fanfares) are synthesized dynamically in real-time using the native Web Audio API.
Authentic Retro Aesthetic: Deep black/green DOS terminal visuals, CRT scanline overlays, phosphor glow effects, and classic arcade typography.
Viewport-Fit Architecture: Dynamically scales to fit any screen without scrolling, featuring toggleable Aspect Ratio modes (AUTO, 16:9 Widescreen, 4:3 Classic CRT).
Advanced Targeting Engine: Real-time 60FPS <canvas> ballistic physics featuring 180° turret rotation, bullet tracers, particle systems, and intelligent "lowest-threat-first" target locking.
Persistent Flight Logs: Tracks personal bests, WPM, and accuracy locally across 4 distinct arsenal difficulty modes (Lowercase, Mixed Case, Alphanumeric, Maximum Threat).
